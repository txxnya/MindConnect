# 🧠 MindConnect

A full-stack mental health platform that enables users to book appointments with mental health professionals while fostering a supportive community where people facing similar challenges can connect and interact.

Built with a modern TypeScript stack using React, Express, PostgreSQL, and Prisma ORM.

---

## ✨ Features

- 🔐 JWT Authentication
- 👥 Role-Based Access Control (Admin & User)
- 📅 Appointment Booking System
- 👨‍⚕️ Doctor Management
- 🏥 Admin Dashboard
- 💬 Community Platform for Patients
- 📱 Responsive UI
- ⚡ RESTful API Architecture
- 🗄️ PostgreSQL Database with Prisma ORM
- ☁️ Cloud Deployment using Vercel & Neon PostgreSQL

## 📂 Project Structure

The project follows a monorepo architecture with shared TypeScript types between the frontend and backend.

Core entities include:

- Users
- Doctors
- Appointments
- Community
- Authentication
